# MyID — учебное PWA-приложение

Это учебный макет цифровых документов в виде сайта/PWA.

## Что внутри
- `index.html` — интерфейс
- `style.css` — мобильный дизайн
- `app.js` — окна документов, профиль и QR
- `manifest.webmanifest` — установка как приложения
- `sw.js` — кэш для офлайн-работы
- `icon.svg` — иконка

## Как запустить
Для обычного просмотра можно открыть `index.html`.

Для установки на телефон как приложение сайт должен быть размещён по HTTPS (например, на GitHub Pages или другом хостинге).

На Android в Chrome: меню → «Установить приложение» / «Добавить на главный экран».

На iPhone в Safari: «Поделиться» → «На экран Домой».

## Важно
Это учебный макет, не официальный государственный сервис и не документ.
